# Deutschland flieht – Webseiten

Dieses Repository enthält zwei eigenständige Entwürfe der Kampagne „Deutschland flieht“.

## Projekte

### `webseiten/digitales-mahnmal-angular`

Die umfangreichere Angular-Version mit Landingpage, Petition, Rechtstexten,
Bildmaterial und einer animierten 3D-Deutschlandfahne.

```powershell
cd webseiten/digitales-mahnmal-angular
npm install
npm start
```

Produktions-Build:

```powershell
npm run build
```

### `webseiten/kampagnen-onepager-react`

Die neuere, kompakte Onepager-Version auf Basis von React und Vite.

```powershell
cd webseiten/kampagnen-onepager-react
npm install
npm run dev
```

Produktions-Build:

```powershell
npm run build
```
